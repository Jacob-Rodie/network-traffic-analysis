# Network Traffic Analysis & Troubleshooting

This project demonstrates the use of network troubleshooting tools and packet analysis to observe how devices communicate across a network.

The focus of this project is understanding common network protocols, testing connectivity, analyzing traffic with Wireshark, and documenting troubleshooting steps relevant to IT Help Desk and Technical Support roles.

## Environments and Technologies Used

* Windows
* Linux
* Wireshark
* Command Prompt / PowerShell
* Terminal
* TCP/IP
* DNS
* ICMP
* SSH
* RDP

## Project Overview

This project will document network communication and troubleshooting through hands-on connectivity testing and packet analysis.

The project will include:

* Testing connectivity between devices
* Using `ping` to test network communication
* Capturing and analyzing ICMP traffic
* Observing DNS traffic
* Examining TCP/IP communication
* Testing remote-access protocols
* Reviewing source and destination IP addresses
* Observing how firewall or network rules affect connectivity
* Troubleshooting failed network connections
* Verifying connectivity after changes
* Documenting packet captures and observations
